Open 2048 is a lightweight and feature-rich port of the classic 2048 puzzle game. Built from the ground up with **Jetpack Compose**, it offers smooth animations, a clean UI, and several game modes to keep you challenged.

## ✨ Features

- 🚫 **100% Ad-Free**: No interruptions, no banners, no trackers. Just the game.
- 🎨 **Multiple Themes**: Choose from **Light**, **Dark**, or the nostalgic **Classic** theme.
- ⏪ **Undo Support**: Made a wrong move? Easily undo your last step.
- 🕒 **Game Modes**:
  - **Classic**: The timeless 4x4 challenge.
  - **Daily Challenge**: A new seed every day. Compete with friends on the same board!
  - **Blitz**: How high can you score before the time runs out?
- 📊 **Statistics**: Track your moves, elapsed time, and best scores for every mode.
- 💾 **Auto-Save**: Never lose your progress. The game saves automatically so you can resume anytime.

## 🚀 Download

You can download the latest `.apk` from the [Releases](https://github.com/scottmangiapane/open-2048/releases) page and sideload it onto your Android device.

## 🛠 Tech Stack

- **Language**: [Kotlin](https://kotlinlang.org/)
- **UI Framework**: [Jetpack Compose](https://developer.android.com/jetpack/compose)
- **Architecture**: MVVM (Model-View-ViewModel)
- **State Management**: Kotlin Coroutines & Flow
- **Persistence**: DataStore / Preferences

## 🏗 Building from Source

1. Clone the repository:
   ```bash
   git clone https://github.com/scottmangiapane/open-2048.git
   ```
2. Open the project in **Android Studio Hedgehog** (or newer).
3. Build and run on your device or emulator.
